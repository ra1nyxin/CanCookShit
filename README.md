# 能煮屎 / CanCookShit

饥荒联机版模组，让粪肥和鸟粪成为可以直接食用和入锅的食材。

- 粪肥：基础饱食度 +8、理智值 -15。
- 鸟粪：基础饱食度 +6、理智值 -25。
- 每份入锅提供 0.5 肉度和 0.5 怪物度，可以放进冰箱和盐盒，也可以喂给其他玩家。
- 食用时有中文角色台词，检查台词沿用游戏原版。角色自身的食物效果仍按原版结算。
- 喂皮弗娄牛可增加顺从、驯服、生命和饱食：粪肥分别为 4%、0.3%、5 和 8；鸟粪为 2%、0.15%、3 和 6。

服务器和所有客户端都需要启用此模组。

## English

This Don't Starve Together mod makes manure and guano edible and usable as crock pot ingredients. Manure has base values of +8 hunger and -15 sanity; guano has +6 hunger and -25 sanity. Each provides 0.5 meat and 0.5 monster value. Both can be stored in ice boxes and salt boxes or fed to other players. Eating dialogue is currently in Chinese; inspection dialogue remains unchanged. Character-specific food modifiers still apply.

The server and all clients must enable the mod.

Feeding a beefalo manure grants 4% obedience, 0.3% domestication, 5 health and 8 hunger; guano grants 2%, 0.15%, 3 and 6 respectively.
